# نوبت‌یار | NobatYar

پروژه رابط کاربری فارسی و راست‌به‌چپ برای معرفی تخصص‌ها، بیماری‌های رایج و پزشکان دارای نوبت امروز. ساخته‌شده با React 18، Vite، Vazirmatn و Lucide.

## اجرای پروژه

در PowerShell ویندوز، در پوشه همین نسخه:

```powershell
npm.cmd ci
npm.cmd run lint
npm.cmd run build
npm.cmd run dev -- --port 5176
```

> اگر پورت مشغول است، پورت دیگری انتخاب کنید. این نسخه را ابتدا جدا از پروژه اصلی اجرا کنید.

## ساختار

- `src/components/`: بخش‌ها و کامپوننت‌های رابط کاربری، هرکدام با CSS مرتبط خود
- `src/styles/tokens.css`: مقادیر مشترک رنگ، تایپوگرافی، فاصله، شعاع، سایه و موشن
- `src/styles/buttons.css` و `src/components/Button.jsx`: خانواده مشترک دکمه‌ها
- `src/data/mock.js`: پزشکان نمونه و اطلاعات نمایشی
- `public/images/doctors/`: چهار تصویر نمونه پزشکان
- `src/components/IranHolidays.js`: داده تعطیلات سال ۱۴۰۵ و بارگذاری سال‌های پشتیبانی‌شده

این پروژه نمایشی است؛ جست‌وجو، رزرو واقعی و صفحات اختصاصی بیماری‌ها هنوز به سرویس بک‌اند متصل نیستند. تصاویر پزشکان نیز نمونه ساختگی‌اند و نماینده اشخاص واقعی نیستند.

راهنمای توکن‌ها و اصول طراحی در `DESIGN-SYSTEM.md` قرار دارد.
